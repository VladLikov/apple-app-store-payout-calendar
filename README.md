# Apple App Store Payout Calendar

A subscribable calendar with estimated Apple App Store payout dates and the exact period covered by each payout.

Example event:

> 🍎 Apple payout · Aug 30 – Sep 26

## Subscribe

### iPhone / iPad / Mac

Use this subscription URL:

`webcal://raw.githubusercontent.com/VladLikov/apple-app-store-payout-calendar/main/apple-payouts.ics`

HTTPS feed:

`https://raw.githubusercontent.com/VladLikov/apple-app-store-payout-calendar/main/apple-payouts.ics`

On iPhone or iPad:

Calendar → Calendars → Add Calendar → Add Subscription Calendar

Then paste the `webcal://` URL above.

## Source

Dates and Apple fiscal periods are based on RevenueCat's Apple fiscal calendar and payment-date estimates:

https://www.revenuecat.com/blog/growth/apple-fiscal-calendar-year-payment-dates

Apple does not publish a fixed official payout schedule, so payout dates are estimates and may shift.

## Coverage

Current feed includes payout events from **October 1, 2026 through November 4, 2027**.
